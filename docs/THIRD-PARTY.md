# Drittlizenzen

- **Open Food Facts** (Produktdaten per Barcode): Datenbank unter ODbL 1.0, Inhalte unter DbCL. Quellenhinweis in der App, im Export und in der Datenschutzerklärung. Bilder werden nicht verwendet oder gespeichert.
- **barcode-detector** (MIT): Barcode-Erkennung, wenn der Browser keine eigene hat.
- **zxing-wasm / zxing-cpp** (MIT / Apache-2.0): die darin enthaltene WebAssembly-Datei, ausgeliefert von der eigenen Domain unter `/vendor/`.
